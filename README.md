# CSO Accreditation System

A web-based accreditation management system for Civil Society Organizations (CSOs), developed for the Department of Agriculture - Western Visayas. It streamlines the accreditation process, project monitoring, financial reporting, and performance ranking of CSOs.

## Features
- CSO registration and accreditation application
- Document submission and admin review workflow
- Project and milestone tracking
- Financial report management
- CSO performance ranking system
- Renewal application management
- Announcements and notifications

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL (MariaDB)
- **Frontend:** HTML, CSS, JavaScript, Bootstrap (SB Admin 2)
- **Email:** PHPMailer
- **Icons:** FontAwesome

## Setup
1. Clone the repository
2. Import `DA/sql/cso (10).sql` into your MySQL database
3. Configure your database connection in `DA/include/`
4. Place the project inside your web server's root (e.g. `htdocs/` for XAMPP)
5. Access via `http://localhost/DA`
